# Simple Calculator Project

A beginner-friendly calculator project built using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear display option
- Simple and clean UI

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Open the project folder
2. Run the `index.html` file in your browser
